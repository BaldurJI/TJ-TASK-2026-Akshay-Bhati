# GitHub Profile Explorer

A clean, modern React Native (Expo) mobile application that lets you search for
any GitHub user and explore their public profile using the **official GitHub REST API**.

Built with **React Native + Expo + TypeScript + React Navigation**.

---

## Features

- Search GitHub users
- View profile picture
- View username and name
- View bio
- View followers / following
- View public repositories
- View GitHub profile URL, location, company, website and account creation date
- GitHub REST API integration (real data — no mock data)
- Mobile navigation (Search → Profile, back to Search)
- Error / loading / empty states
- Handles: user not found (404), network errors, rate-limit errors, empty input
- Keyboard-friendly search input (`returnKeyType="search"`, dismiss on submit)

---

## Technologies

- React Native
- Expo (SDK 51)
- TypeScript
- React Navigation (native stack)
- GitHub REST API
